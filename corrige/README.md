# Corrigé

Une solution possible pour chaque exercice, avec la même arborescence que les énoncés. D'autres solutions sont
justes : si vos tests passent, votre version est bonne.

Cherchez d'abord par vous-même ; ouvrez le corrigé pour vérifier ou quand vous êtes bloqué depuis longtemps.

```bash
cd corrige
cargo test -p ch15-traits     # les tests de la correction passent
```

Le chapitre 19 se lance comme dans les énoncés : `cd corrige/ch19-ffi && ./lancer.sh`.
